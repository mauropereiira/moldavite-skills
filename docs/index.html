Five maps. No invented territory.

Each skill owns one clear job. Agents load only the instructions relevant to the work in front of them.

01 / MARKDOWN [[ ]]

Write notes that survive the editor.

Conservative Markdown, preserved YAML, note colors, wiki-link order, tags, and the Obsidian syntax Moldavite intentionally does not support.

Open skill → 02 / FORGES ~/

Know where every note belongs.

Forge layout, locked-note boundaries, nested paths, direct edits, and refresh behavior.

Open skill → 03 / MCP ::

Use the seven tools that exist.

Exact arguments, search modes, write gates, full-file replacement, and safe retries.

Open skill → 04 / DAILY W31

Journal without guessing the date.

Local daily dates, ISO week years, deduplication checks, and supported template tokens.

Open skill → 05 / PORTABILITY ZIP

Move knowledge without losing meaning.

Backups, Merge versus Replace, settings scope, exports, and precise Obsidian import conversions and limits.

Install once. Let context do the routing.

Pick your client. The skill descriptions tell it exactly when each instruction set should load. 

npx skills add https://github.com/mauropereiira/moldavite-skills

Skills CLI discovers all five skills and lets you choose which clients receive them. 

mkdir -p ~/.config/opencode/skills && git clone https://github.com/mauropereiira/moldavite-skills.git ~/.config/opencode/skills/moldavite-skills

Restart OpenCode after installation. Nested SKILL.md files are discovered automatically. 

/plugin marketplace add mauropereiira/moldavite-skills
/plugin install moldavite@moldavite-skills

Add the marketplace, then install the Moldavite skill collection.

Skills provide instructions. To let an agent query your notes, connect Moldavite's local MCP server too.

moldavite --mcp

Skills teach. MCP acts.

The pack tells agents how to work. Moldavite's app binary gives them a local, permissioned path to the Forge. Nothing is uploaded to make that connection work.

local stdio 
$ claude mcp add moldavite -- "/Applications/Moldavite.app/Contents/MacOS/moldavite" --mcp
