# Forge Layout Reference

## Path selection

| Note kind | Path | Nesting |
| --- | --- | --- |
| Daily | `daily/YYYY-MM-DD.md` | No |
| Weekly | `weekly/YYYY-Www.md` | No |
| Standalone | `notes/<slug>.md` | Yes, below `notes/` |
| Locked | Same logical path ending in `.md.locked` | Never access |

MCP accepts note paths beginning with `daily/`, `weekly/`, or `notes/` and ending in `.md`. `list_notes` accepts `daily`, `weekly`, `notes`, or a nested folder below `notes/`.

## App-managed content

Treat these paths as implementation data rather than agent-editable notes:

- `.trash/`: deleted notes and retention metadata
- `.plugins/`: installed plugin code and manifests
- `.index/`: derived semantic vectors
- `templates/`: JSON maintained through Moldavite's template UI
- `images/`: attachments maintained by note operations

Root `AGENTS.md` and `.gitignore` may be generated by Moldavite's Agent-ready Forge feature. Read `AGENTS.md`; do not replace either root file unless the user explicitly requests it.

## Concurrent edits

Moldavite's GUI protects saves with body hashes and conflict copies. External direct writers do not participate in that protocol. Minimize race windows:

1. Read immediately before changing.
2. Keep edits narrow.
3. Abort when content changed unexpectedly.
4. Prefer MCP for controlled note replacement.
5. Ask the user to close or reload an actively edited note when necessary.
